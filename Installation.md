# Installation Guide

The following is an installation guide for installing one of the following supported launchers:
- Prism Launcher/PineconeMC
- Modrinth Launcher
- Default Launcher
- TLauncher
#  Prism Launcher / PineconeMC
## Or any Prism Launcher fork

### 📥 Installation & Setup Guide
1. Download the most recent modpack release file from the #modpack channel in the Discord server
2. Open Prism Launcher
3. Locate the .mrpack file you’ve downloaded in your file explorer or finder
4. Drag the .mrpack into the Prism Launcher window. This should open a pop-up that lets you set up the Minecraft instance.
5. Launch the instance you just set up, and you’ll be able to join the server in the Multiplayer screen.
6. At this point, you should be Gucci. Have fun mister/misterette :)

# Modrinth Launcher
### 📥 Installation & Setup Guide

1. Download the most recent modpack release file from the #modpack channel in the Discord server.
2. Open Modrinth Launcher.
3. Locate the .mrpack file you’ve downloaded in your file explorer or finder.
4. Open the modpack with Modrinth and wait for Modrinth Launcher to finish setup.
5. Alternatively, you can install the modpack by creating a new instance and install a modpack.
6. Enjoy and begin your Cobblemon Adventure! (Server address should be inside the after installing correctly)

# TLauncher
### 📥 Installation & Setup Guide

1. Download the Modrinth app from your browser via Modrinth.
2. Go to the #modpack channel under announcements and download the provided modpack file.
3. Once the modpack is downloaded, double-click the file. This will automatically open Modrinth and begin installing the modpack.
4. After installation is complete, locate the modpack in Modrinth (you’ll see a cube icon on the left panel) and click on it.
5. In the top-right corner, click the three vertical dots (⋮) and select “Open Folder.”
6. When the folder opens, select all files using Ctrl + A, then copy them using Ctrl + C.
7. Open TLauncher and click on the TLMods icon in the bottom-right corner.
8. At the top-center of the screen, click on “Create.”
9. In the creation menu:
	- Enter any name you like (e.g., Cobblemon)
	- Set the Loader to NeoForge
	- Set the Game Version to 1.21.1
10. Click “Create” to finish setting up the version.
11. Back in TLauncher, click the folder icon in the bottom-right corner (next to the TLMods logo) to open the file manager.
12. Locate and open the “versions” folder.
13. Find the folder with the name you just created (e.g., Cobblemon) and open it.
14. Delete all existing files inside this folder, then paste the files you copied earlier (Ctrl + V).
15. Close all folders. Make sure the correct version is selected in TLauncher, then click “Enter the Game.” (Note: The first launch may take some time.)
16. Once the game starts, go to Multiplayer, find the server, and double-click it to join.
17. 🎮 Enjoy playing on the 404 Found Cobblemon x Create Server!

# Default Launcher
### 📥 Installation & Setup Guide

1. Follow Modrinth until steps 4-5 ron
2. Download Neoforge 1.21.1 from the official [site](https://neoforged.net/)
3. In the Default Launcher, open the Installations tab and create a new installation
4. Name it, set version to Neoforge 21.1
5. Select Browse Game Directory and search for `C:\Users\SYSTEMNAME\AppData\Roaming\ModrinthApp\profiles\` And search for your modpack from Modrinth
6. Select More options
7. Under JVM ARGUMENTS, replace it with: `-Xmx4G -XX:+UseZGC -XX:+ZGenerational -XX:+DisableExplicitGC -XX:+PerfDisableSharedMem` (You may replace the 2 in -Xmx2G with any number to allocate more ram, i suggest anything between 3-6)
8. Once the game starts, go to Multiplayer, find the server, and double-click it to join.
9. 🎮 Enjoy playing on the 404 Found Cobblemon x Create Server!
